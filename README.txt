# DOKKYO Mark Assistant

獨協大学体育会ヨット部向けのマーク設置・GPS誘導補助ツールです。

## 起動・配置
1. ZIPを展開し、`DOKKYO_Mark_Assistant` フォルダ内の構成を維持してください。
2. `index.html`、`manifest.webmanifest`、`sw.js`、`assets/` を同じ階層関係のままHTTPS対応サーバーへ配置してください。
3. 地図表示にはインターネット接続が必要です。Leafletと地図タイルは外部サービスを利用します。
4. GPSおよびPWA機能はHTTPS環境での利用を推奨します。

## 注意事項
- 本ツールは運営補助用です。実際の設置・安全判断を代替するものではありません。
- GPS測位誤差、通信状況、磁気偏差、現場環境などにより表示値と実際の状況が異なる場合があります。必ず現場で確認してください。
- お客様用リンクにはコース情報および登録済みマークの座標が含まれます。送信先に注意してください。
- お客様用リンクのLINE送信では、LINE画面への遷移と文面入力までを行います。最終的な送信操作は利用者が行ってください。
